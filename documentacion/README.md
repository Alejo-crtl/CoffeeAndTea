| `Diagrama_MER_CoffeeAndTea_v1.1.drawio` | Diagrama MER para diagrams.net. |
| `Sistema-de-Gestion-de-Pedidos-de-Cafeteria_v1.1.pptx` | Presentación actualizada del proyecto. |

## Versión histórica

La versión 1.0 (prototipo de 5 tablas) se conserva en el paquete documental
original, no en esta carpeta, para evitar confusiones con la versión vigente.
