CoffeeAndtea - Sistema de gestión por páginas
=============================================

QUÉ INCLUYE
-----------
El sistema tiene cuatro páginas independientes:

1. Inicio    (index.php)     -> hero, resumen de la base y video institucional.
2. Gestión   (gestion.php)   -> CRUD de categorías, clientes, productos,
                                pedidos y detalles.
3. Reportes  (reportes.php)  -> cinco reportes con procedimientos de PostgreSQL.
4. Manual    (manual.php)    -> manual completo en Markdown, con índice.

La navegación se hace con enlaces normales y siempre en la misma pestaña.
No se abren ventanas ni pestañas nuevas.

UBICACIÓN
---------
El proyecto está publicado en:

C:\laragon\www\CoffeeAndtea

CÓMO ABRIR
----------
1. Haz doble clic en:

   C:\laragon\www\CoffeeAndtea\abrir.bat

   Si Apache ya está activo, se abre el navegador en
   http://coffeeandtea.test/. Si no, el mismo archivo inicia un servidor
   PHP de respaldo en http://localhost:8080/.

2. También puedes abrirlo manualmente:
   - Abre Laragon.
   - Pulsa "Start All" si Apache o PostgreSQL no están iniciados.
   - Abre en el navegador:

     http://localhost/CoffeeAndtea/

     O el vhost:

     http://coffeeandtea.test/

RESPALDO
--------
Si Laragon no está disponible, ejecuta:

   scripts\iniciar.bat

Ese archivo llama a abrir.bat. Se abre http://localhost:8080/ y se detiene
cerrando la ventana negra o presionando Ctrl+C.

IMPORTANTE
----------
No abras los archivos .php con doble clic: necesitan ejecutarse desde Apache
o desde el servidor de respaldo.

El proyecto tiene una sola página de inicio (index.php) y tres páginas más:
gestion.php, reportes.php y manual.php. No hay copias ni redirecciones
antiguas dentro de php\lib\.

Las fechas y horas se manejan en la zona America/Bogota (hora de Colombia).
Si necesitas otra zona, define la variable de entorno APP_TIMEZONE antes de
iniciar el servidor.

GESTIÓN DE DATOS
----------------
Cada pestaña de gestion.php tiene un formulario y un listado con acciones
Editar y Eliminar.

Orden recomendado para registrar:
1. Categoría
2. Cliente
3. Producto       (requiere una categoría)
4. Pedido         (requiere un cliente)
5. Detalle        (requiere un pedido y un producto)

Reglas principales:
- No se puede eliminar una categoría que tenga productos.
- No se puede eliminar un cliente que tenga pedidos.
- No se puede eliminar un producto que aparezca en detalles de pedido.
- Al eliminar un pedido se eliminan también sus detalles, en una transacción.
- El total del pedido se calcula automáticamente con los detalles.
- Si un detalle cambia de pedido, se recalculan el pedido anterior y el nuevo.
- En Detalles se agregan varios productos distintos en un solo envío. Se
  guardan todos en una transacción y no se permite repetir un producto.

Los avisos de éxito y error se muestran como notificaciones flotantes
(toasts) en la esquina superior derecha.

REPORTES
--------
Se usan los procedimientos almacenados con refcursor:
- sp_reporte_ventas_diarias
- sp_reporte_top_productos
- sp_reporte_clientes_vip
- sp_reporte_bajo_stock
- sp_reporte_ingresos_categoria

El reporte de bajo stock permite indicar el límite; por defecto usa 30.
"Ventas del día" solo muestra pedidos con estado PAGADO creados hoy.

MANUAL
------
El contenido está en docs\manual.md. Para cambiarlo, edita ese archivo y
recarga manual.php. La página genera automáticamente el índice a partir de
los títulos. El botón "Imprimir manual" aplica estilos de impresión y el
botón "Descargar .md" entrega el archivo fuente.

La librería Parsedown está incluida en php\lib y se usa en modo seguro.

REQUISITOS
----------
- Laragon con Apache y PHP 8.3; el PHP debe tener las extensiones
  pdo_pgsql, pgsql y mbstring habilitadas.
- PostgreSQL en localhost:5432 con la base CoffeeAndTea.
- La conexión y la contraseña están configuradas en php\lib\conectarBD.php.
- El CRUD, el manual y el video funcionan sin conexión a internet.
- El proyecto debe estar en C:\laragon\www\CoffeeAndtea.

Nota: para probar sin afectar los datos existentes, crea registros temporales
y elimínalos al terminar.
