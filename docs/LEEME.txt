COFFEEANDTEA - SISTEMA DE TIENDA Y GESTION
==========================================

QUE ES
------
Aplicacion web para una cafeteria. Los clientes piden en linea y recogen en
tienda. El pago se hace en el mostrador en efectivo o con tarjeta. El personal
cobra, controla caja, stock, pedidos, usuarios y reportes.


REQUISITOS
----------
- PHP 8.3 con pdo_pgsql, pgsql, mbstring, openssl, fileinfo y gd.
- PostgreSQL 18 en 127.0.0.1:5432.
- Apache/Nginx con el docroot en la carpeta public/, o php -S.
- Navegador moderno.


INSTALACION RAPIDA
------------------
1. Copia .env.example a .env y edita la conexion:

   Copy-Item .env.example .env
   notepad .env

2. Crea la base y carga el esquema:

   $env:PGPASSWORD='tu_clave'
   psql -U postgres -h 127.0.0.1 -d postgres -c "CREATE DATABASE coffeeandtea_qa;"
   psql -U postgres -h 127.0.0.1 -d coffeeandtea_qa -f db\schema.sql

3. Para datos de demostracion (solo desarrollo):

   psql -U postgres -h 127.0.0.1 -d coffeeandtea_qa -f db\seed-demo.sql

4. Arranca el servidor:

   scripts\iniciar.bat

   O manualmente:

   php -S localhost:8000 -t public

5. Abre http://localhost:8000/


ADMINISTRADOR
-------------
Con datos demo:
  Correo:      admin@coffeeandtea.local
  Contrasena:  Admin123!

En una instalacion limpia crea el administrador con:

  php bin\crear-admin.php --nombre="Administrador" --correo="admin@tudominio.com"

El script muestra una contrasena temporal una sola vez y obliga a cambiarla.


ROLES
-----
Visitante  -> tienda, carrito, checkout y consulta de pedido.
CLIENTE    -> lo anterior mas su cuenta e historial.
ENCARGADO  -> pedidos, cobro, caja, stock y reportes. Sin carrito ni cuenta.
ADMIN      -> todo lo de gestión y administración. Sin carrito ni cuenta.


REGLAS IMPORTANTES
------------------
- Solo recogida en tienda. No hay domicilios.
- El stock se descuenta al confirmar el pago, no al crear el pedido.
- El precio del detalle queda congelado para pedidos anteriores.
- El efectivo exige caja abierta.
- Cancelar un pedido pagado exige reembolso y devuelve el stock.
- Si el pedido ya está en preparación o listo, el reembolso es del 50%.
- No se puede cancelar un pedido entregado.
- No se puede desactivar al ultimo administrador activo.


ESTRUCTURA
----------
public/              Document root. Solo esta carpeta se publica.
app/php/lib/         Logica: auth, pedidos, caja, correo, auditoria.
app/php/vistas/      Plantillas.
bin/crear-admin.php  Alta del administrador inicial.
db/schema.sql        Esquema completo.
db/seed-demo.sql     Datos demo (no usar en produccion).
db/asignar-imagenes.sql  Asigna fotos a productos existentes.
db/migraciones/      Migracion desde CoffeeAndTea.
docs/manual.md       Manual de usuario.
qa/                  Plan, casos, RBAC e informe.
tests/               Pruebas PHP y Playwright.
storage/             Logs (se crea solo; no se entrega).


MIGRACION
---------
Lee db\migraciones\README.md. La migracion conserva:
6 categorias, 11 clientes, 15 productos, 12 pedidos y 22 detalles.
Se prueba primero en una copia; nunca modifica CoffeeAndTea.


CORREO
------
Desarrollo sin SMTP:
  MAIL_DRIVER=log
  Los correos quedan en storage\mail.log.

Desarrollo con Mailpit:
  MAIL_DRIVER=smtp
  SMTP_HOST=127.0.0.1
  SMTP_PORT=1025
  SMTP_ENCRYPTION=none

Produccion con Gmail:
  MAIL_DRIVER=smtp
  SMTP_HOST=smtp.gmail.com
  SMTP_PORT=587
  SMTP_ENCRYPTION=tls
  SMTP_USER=tu_correo@gmail.com
  SMTP_PASS=contrasena_de_aplicacion


PRUEBAS
-------
PHP:
  $env:DB_NAME='coffeeandtea_qa'
  $env:DB_USER='postgres'
  $env:DB_PASS='tu_clave'
  php tests\run.php

Playwright:
  npm install
  npx playwright install chromium
  npx playwright test


SEGURIDAD
---------
- No entregues el archivo .env.
- No publiques la raiz del proyecto, solo public/.
- Usa HTTPS y APP_COOKIE_SECURE=true en produccion.
- Usa APP_ENV=production y APP_DEBUG=false.
- Cambia las contrasenas demo.
- Programa respaldos de la base.
